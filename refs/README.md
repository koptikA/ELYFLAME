# Референсы ElyFlame

Каждый референс — отдельная строка в таблице ниже. Сами файлы (скрины, видео) кладутся в эту папку рядом с таблицей. Когда библиотека референсов (`reference-library/`) будет готова, все записи из таблицы перенесём туда.

| Файл или ссылка | Что здесь важно | Для какого экрана |
|---|---|---|
| [ballerina-dance.com](https://ballerina-dance.com/) ([Awwwards](https://www.awwwards.com/sites/ballerina)) | Один тёплый цвет (#FF9398) на белом, много воздуха, движение ощущается как танец. Взять настроение. WebGL не повторяем, он не подходит для стека на чистом HTML, CSS и JS | Главная, hero |
| [mouginsendanse.fr](https://www.mouginsendanse.fr/) ([Awwwards](https://www.awwwards.com/sites/mougins-en-danse)) | Сдержанная премиальность, типографика главная, переходы на CSS, сделано на чистом JS. Близко к нашему стеку | Типографика, About |
| [ballettech.org](http://ballettech.org/) ([Awwwards](https://www.awwwards.com/sites/ballet-tech)) | Сайт вырос из существующего логотипа, есть видео в hero. У нас так же: сайт строится вокруг знака-пламени | Hero с видео |
| [CodePen: линия рисуется при скролле](https://codepen.io/Tonkz/pen/aVrzaR) | Приём stroke-dashoffset: SVG-линия прорисовывается по мере скролла. Основа для идеи «лента через весь сайт» | Сквозной декор |
| [CodePen: объект движется по пути при скролле](https://codepen.io/yesvin/pen/XymwvX) | Точка-искра движется по SVG-пути. Так можно показать «путь от Level 1 до Level 6» | Подбор класса, уровни |
| `header-kidstrong-mobile.png`, `header-kidstrong-desktop.png` — [kidstrong.com](https://www.kidstrong.com/) | ✅ В шапке нет ни Enroll, ни Register. На странице одно главное действие — «Select your location to get started». Довод за одну главную кнопку | Шапка, CTA |
| `header-goldfish-desktop.png`, `header-goldfish-mobile.png` — [goldfishswimschool.com](https://www.goldfishswimschool.com/) | ✅ В шапке только навигация, запись вынесена в hero одной кнопкой. «Register Through Our Portal» — ссылка в тексте страницы, для тех, кто уже решил | Шапка, Register |
| `header-littlegym-desktop.png`, `header-littlegym-mobile.png` — [thelittlegym.com](https://www.thelittlegym.com/) | ❌ Антипример: две кнопки одинакового веса, «Enroll Now» и «Free Intro», плюс «Find My Gym» в hero. Три конкурирующих действия на одном экране. Причём у них можно записаться и без пробного, а у ElyFlame — только после пробного | Шапка, чего избегать |
