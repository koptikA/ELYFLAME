# ElyFlame — фото и видео

Для команды (Кирилл, Иван, Винди) и через Кирилла для клиента. 25 сентября 2026. Как фото учениц попадают на сайт: где стоят, правила для фото детей, единый стиль, процесс обработки и требования к файлам. Связанные решения — в `docs/decisions.md`, открытые вопросы — 19, 22 и 25–29 в `docs/client-questions.md`.

## Где мы сейчас

- Родители согласны на публикацию фото на сайте (вопрос 20). Письменные согласия на каждого ребёнка в кадре ещё нужно подтвердить (вопрос 25).
- Оригиналов фото и видео пока нет (вопросы 19, 27, 28). Копии из Instagram сжаты до ~1080 px, логотип и розовый фон впечатаны, поэтому при квадратной обрезке логотип режется.
- Пока файлов нет, на сайте и в Figma стоят серые заглушки. Блоки помечены `data-requires-content`.
- Минимум для запуска — шесть и больше настоящих фото (бриф, PRD).

Первый экран и подвал остаются иллюстрациями: силуэт гимнастки и «команда» из силуэтов. Иллюстрацию никто не примет за ученицу. Это отступление от ТЗ 3.1, нужно подтверждение клиента (вопрос 29). У страницы Stretching свой силуэт — гимнастка на шпагате: `assets/gymnast/split.svg` (символ `split`), обведён potrace из сгенерированной `split.jpg`, так же как `team.svg`.

## Правила для фото детей

- Только дети, чьи родители подписали письменное согласие на фото (photo release). Если в групповом кадре есть ребёнок без согласия, кадр не берём. Список согласий хранит академия.
- Если родитель отзывает согласие, фото сразу убираем с сайта и из Figma.
- Без имён: alt-текст описывает сцену («Гимнастки на тренировке с лентами») и не называет ни ребёнка, ни школу, ни время занятий.
- При экспорте удаляем метаданные EXIF, в том числе геолокацию.
- Берём движение, выступления, общие планы. Не берём крупные планы тела, неудачные ракурсы в купальниках и раздевалки.
- AI только улучшает кадр (увеличение, свет, цвет) и не меняет людей. Учениц не генерируем (решение от 24.09).
- Обработка во внешнем AI-сервисе (Figma Weave) — только с согласия клиента: родители согласились на публикацию, а не на обработку сторонним сервисом (вопрос 26). Без такого согласия цветокоррекцию делаем локально и не увеличиваем фото.

## Единый стиль

1. **Эталон.** 2–3 характерных кадра доводим вручную до нужного вида: тёплый баланс белого, светлые тона уходят в кремовый цвет фона сайта (`--paper`), тени тёплые и глубокие, без перенасыщения, кожа естественная. Эталон утверждает Алена.
2. **Фирменный слой в коде.** На сайте поверх фото CSS накладывает мягкий градиент бренда, а в тёмных секциях — дуотон маджента → оранжевый (решение от 24.09). Он одинаковый для всех фото, и его можно подправить без повторной обработки.
3. **Проверка серии.** Перед публикацией смотрим все обработанные кадры рядом как одну серию.

## Процесс

| Шаг | Кто | Что |
|---|---|---|
| 1. Отбор | Алена | Выбирает кадры по правилам выше; резкие, не меньше 1600 px по длинной стороне |
| 2. Обработка | Винди собирает workflow в Weave, Claude запускает | Опубликованный workflow Weave только с неизменными шагами: увеличение, если кадр маленький, шумоподавление, цветокоррекция по эталону. Генеративных шагов, которые могут изменить лицо или тело, нет. Claude запускает его через Figma MCP одной партией; каждый запуск тратит кредиты Weave, поэтому сначала подтверждение |
| 3. Проверка | Claude, потом Алена | Страница «до/после» со всеми кадрами рядом; проверяем, что люди не изменились. Финальное «да» за Аленой |
| 4. Экспорт | Claude | Кадрирование под место (1:1 для галереи), удаление EXIF, WebP трёх размеров в `assets/photos/`; alt-тексты на EN/RU/UA через `tools/i18n.py` |
| 5. Figma | Алена или Claude | Фото перетаскивается на прямоугольник «Photo 1…6» на обеих страницах Home |
| 6. WordPress | клиент, после запуска | Загружает любое фото в место галереи; сайт сам обрежет его до квадрата (`object-fit: cover`) |

Чтобы запускать Weave отсюда, Алене один раз нужно связать аккаунт Figma с Weave: app.weavy.ai/settings?section=profile.

## Куда класть файлы

- **Видео:** `assets/video/performance.mp4`, `performance.webm`, `performance-poster.jpg` — вместо заглушек с теми же именами, сайт подхватит их сам. Один исходник кладём в `assets/video/source/`, оттуда его пережимаем.
- **Оригиналы фото:** `assets/photos/originals/`. Папка в `.gitignore`: в оригиналах есть EXIF и геометки. Обработанные копии без метаданных идут в `assets/photos/` и попадают в репозиторий.
- **Figma:** фото перетаскивается на прямоугольник «Photo 1…6».

## Видео

- Беззвучный ролик по кругу, 10–20 с, 16:9, 720p, без текста в кадре: MP4 (H.264) и WebM, до 3 МБ каждый (или исходник, пережмём сами).
- Выступление или занятие, снятое без тряски и без впечатанного логотипа.
- Постер — первый кадр.
- На сайте это фоновое видео без элементов управления: играет, только пока блок на экране, а при «уменьшении движения» стоит на постере (`docs/behavior-spec.md`, раздел 7).
